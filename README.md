# 💰 Money Matters

**Track smart. Save smarter.** A personal finance tracker with expenses, goals, spending habits, and a simple budget—plus light gamification (XP, levels, streaks).

## Features

- **Home** – Quick-add expenses (amount, description, category), recent list with delete, and a summary (today’s spend, this month, daily budget if set).
- **Goals** – Create savings goals with target amounts, progress bars, custom or quick deposits (+₹100, ₹500, ₹1000), and delete.
- **Habits** – Spending by category (from your expenses) and total spent this month.
- **Budget** – Set monthly income, fixed expenses, and savings goal; see your **safe daily limit**.
- **Gamification** – Earn 10 XP per expense, level up every 100 XP, and build a day streak when you log on consecutive days.
- **Theme** – Dark (default) and light; preference is saved.
- **Data** – All data is stored in your browser (localStorage); no backend.

## Tech

- React 19 + Vite 7
- No database; runs fully in the browser

## Run locally

```bash
npm install
npm run dev
```

Then open [http://localhost:5173](http://localhost:5173).

## Build

```bash
npm run build
npm run preview
```
